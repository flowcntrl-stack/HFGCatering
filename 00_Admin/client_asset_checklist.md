# HFG Catering — Client Asset Checklist

This checklist tracks the information and assets needed to turn the initial website scaffold into a client-ready production site.

## Business Information
- [ ] Official business name spelling and capitalization
- [ ] Business phone number
- [ ] Business email address
- [ ] Service area
- [ ] Business hours or response window
- [ ] Preferred contact method

## Brand Assets
- [ ] Logo file
- [ ] Preferred logo usage notes
- [ ] Final color preferences beyond lavender, green, and gray
- [ ] Font preferences, if any
- [ ] Brand voice notes

## Website Content
- [ ] Company story / About section
- [ ] Catering services offered
- [ ] Sample menu categories
- [ ] Full menu or downloadable menu file, if available
- [ ] Dietary accommodations
- [ ] Booking process
- [ ] Frequently asked questions

## Media Assets
- [ ] Food photography
- [ ] Event setup photography
- [ ] Team or behind-the-scenes images
- [ ] Short video clips, if available
- [ ] Social media links or handles

## Trust Builders
- [ ] Testimonials
- [ ] Event highlights
- [ ] Certifications or permits, if client wants displayed
- [ ] Partner/vendor references, if applicable

## Technical / Launch Details
- [ ] Domain name
- [ ] Hosting preference
- [ ] Contact form destination email
- [ ] Analytics preference
- [ ] Privacy policy requirement
- [ ] Final launch approval contact
